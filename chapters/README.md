## 📐 章节成稿模板

每章按以下 7 段结构：

1. **核心概念**（英文术语 + 中文译名 + 一句话定义）
2. **底层逻辑**（为什么需要 / 三层结构 / 终止条件）
3. **架构示意**（Mermaid 流程图）
4. **HCI / UX 落点**（用户怎么看见 + 怎么建立信任）
5. **代码示例**（Python + LiteLLM，最小可运行）
6. **我的实战映射**（脱敏业务案例）
7. **面试能讲版本**（一句话 / 三句话 / 完整 STAR）
