## 三十秒版

反思（Reflection）给 AI 的产出增加一道"二次检查"：先按标准核对已有结果，再根据反馈改进。核心流程是「生成 → 评审 → 修订」，评审和修订可以合并或拆分。修改发生在推理阶段（inference），只作用于当前这份结果，不涉及训练。

## 最值得记住的四个事实

1. **反思不保证有效。** Self-Refine 报告的「约 20 个百分点提升」是作者对七类任务的整体总结，各任务指标不同；Valmeekam 的规划研究则发现 GPT-4 自我批评反而降低表现。收益要结合任务和评测判断，落到产品上就是「按场景开启」而非「默认全开」。
2. **课程 SQL 示例是 87% → 95%**，绝对提升 8 个百分点。这是说明评估方法的示例，对外承诺要用自身业务样本的验证结果。
3. **可靠的外部反馈是关键。** 自我纠错综述指出，适合任务的可靠外部工具或知识能帮助改进反馈；仅靠模型自身反馈的效果受任务和设置影响。
4. **模型裁判要校准。** 存在位置偏差（倾向于第一个选项）和自偏好（倾向于自身输出），评分表需要专家样本校准后才能对外展示。
